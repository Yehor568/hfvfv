# Довідник: підбір товарів під Meta Ads

> Стан на 02.10.2026. Розрахунки — [model/Product_Hunter_Model.xlsx](../model/Product_Hunter_Model.xlsx), деталі — [CONCEPT.md](./CONCEPT.md).

## Бізнес-модель
Лендінг → лід (подія `Lead` пікселя) → підтвердження в LP-CRM → відправка з оплатою при отриманні. Ринок продажу — тільки Україна. США, ЄС і Китай — джерела сигналів.

## Цільова аудиторія
- **Жінки 45–65+** — 48–72 % спенду; найдешевші ліди у 55+. Друга група — чоловіки 45+.
- CTR росте з віком: ~3 % (18–24) → 7–9 % (65+).
- Мотивація: «полегшити побут» (кухня, дім, город, здоров'я). Довіряють «німецькій якості». Головний страх — «не працює / підробка». Найкраще продає відео-демонстрація.

## Економіка

| Параметр | Значення |
|---|---|
| Маржа з товару (продаж − закупка) | 300 ₴ (250–350) |
| Маржа з допродажів | 250 ₴ (200–300), мінус 23 % комісії |
| Апрув / викуп | 64 % / 82 % |
| Витрати на підтверджене замовлення | 23 ₴ |
| Повернення невикупу | 150 ₴ |
| Курс | 41.5 ₴/$ |

```
Дохід з підтвердженого = викуп × (маржа + допродажі × 0.77) − невикуп × 150 − 23   ≈ 354 ₴
Беззбитковий CPL       = апрув × дохід з підтвердженого                              ≈ 232 ₴ ≈ $5.46
Цільовий CPL           = 60 % від беззбиткового                                       ≈ $3.27
```

**Правило:** лід ≤ **$3.27** — добре; **$3.27–5.46** — тонка маржа; > **$5.46** — збиток. Без допродажів беззбиток лише ≈ $3.5.

## Оцінка нового товару (Product Score 0–100)

Кожен блок оцінюється від 0 до 5. Score = Σ(оцінка × вага) / 5 − штраф за ризики (0–20).

| Блок | Вага | 5 балів — це |
|---|---|---|
| Тренд (Google Trends US/EU/UA) | 20 | Росте у США, в Україні ще не на піку |
| Реклама US/EU (Ad Library) | 20 | Багато рекламодавців, реклама живе понад 30 днів |
| Насиченість UA | 15 | Майже немає конкурентів |
| Юніт-економіка | 20 | Маржа > 350 ₴ або легкий допродаж |
| Відповідність ЦА 45+ | 15 | Побут/кухня/здоров'я, «вау» на відео |
| Схожість з переможцями | 10 | Як подрібнювач / блендер / компресор |

**Рішення:** ≥ 70 — в тест · 55–69 — спостерігати · < 55 — відкинути. Якщо очікуваний CPL > $5.46, товар відкидається незалежно від Score.

## Протокол тесту
1. OUTCOME_LEADS, широка аудиторія UA, 3–4 відео-креативи, **$14/день × 3 дні**.
2. **Стоп:** після ~$10 спенду (3 × цільовий CPL) ліди дорожчі за $5.46.
3. **Масштаб:** CPL ≤ $3.27 і апрув ≥ 60 % → $50/день, потім дублі в інші кабінети.
4. Між $3.27 і $5.46 — нові креативи або офер ще на 2 дні.
5. Остаточне рішення — за ціною викупленого замовлення з LP-CRM через 10–14 днів.
